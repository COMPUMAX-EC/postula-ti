Postula TI

Las plataformas donde vale la pena postular a empleos de TI y becas desde Ecuador y LATAM, y las herramientas para buscar vacantes, preparar cada postulación, seguir su estado y saber qué habilidades aprender. Gratis y de código abierto, por DevIALabs.

Descargar (.zip) Ver en GitHub

Cómo usarlo

1. Descarga e instala

Necesitas Node.js 20 o más.

git clone https://github.com/COMPUMAX-EC/postula-ti.git
cd postula-ti
npm ci
2. Tu perfil

Copia perfil.ejemplo.md como perfil.md y complétalo. No se sube a GitHub.

3a. Con Claude Code

Abre la carpeta con Claude Code y pide, por ejemplo:

busca vacantes para mí
prepara la postulación de <enlace>
¿cómo van mis postulaciones?
3b. Solo con scripts
npm run buscar        # vacantes por API
npm run revisar       # cierres y resultados
npm run seguimiento   # panel seguimiento.html
npm run marcar        # marcar enviadas
npm run habilidades   # qué aprender
npm run pdf           # CV y carta en PDF

Skills incluidas

buscar-vacantes

Busca vacantes de TI y becas vigentes para el perfil del usuario (APIs públicas de Get on Board, Workable, Greenhouse y Lever, más las plataformas de plataformas.json), confirma que siguen abiertas, las puntúa de 1 a 10 y propone solo las de 7 o más. Úsala cuando el usuario pida "busca vacantes", "qué hay para mí" o "busca becas".

documentos-postulacion

Organiza los documentos que comparten las postulaciones (cédula, pasaporte, título, récord, traducciones, certificado de inglés, cartas de recomendación, certificados laborales) y redacta los pedidos para conseguir los que faltan. Úsala para "qué documentos me faltan" o "cómo consigo la traducción del título".

mapa-habilidades

Recopila y clasifica las tecnologías y habilidades que piden las vacantes y becas preparadas (quién las pide y cuándo), compara con el nivel del usuario y prioriza qué aprender, con un mini proyecto para la brecha principal. Úsala para "qué debo aprender", "qué piden las empresas".

preparar-postulacion

Prepara una postulación completa a partir de una vacante o beca (README con requisitos, brechas y pasos; CV y carta adaptados de una página; respuestas del formulario; ficha.json para el seguimiento; PDF listos para adjuntar). Úsala cuando el usuario pase un enlace de vacante o elija una de buscar-vacantes.

seguimiento-postulaciones

Lleva el seguimiento de todas las postulaciones (etapas, cola de envío priorizada, documentos que faltan, cierres) y revisa sin iniciar sesión si las vacantes se cerraron, si cambiaron las páginas de becas o si llegó la fecha de resultados. Úsala para "cómo van mis postulaciones", "ya envié X", "qué envío hoy".

Directorio de plataformas

API: datos públicos, se leen automáticamente · Fácil: página o feed sin login · Con navegador: carga con JavaScript · No: correo, LinkedIn o portal con cuenta.

¿Conoces una plataforma que falta? Agrégala a plataformas.json con un pull request en GitHub. Verificado por última vez: 2026-10-23. Las skills nunca envían postulaciones ni inician sesión por ti.
